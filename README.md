# Simply Ummiby Workshop v2

Clean-slate Company Hub for Simply Ummiby.

## Foundation
- React + Vite
- Supabase cloud backend
- Component-first UI architecture
- Admin → Design System as the live internal component gallery
- Permanent module shell: Dashboard, Inventory, Products, Orders & Production, Pricing, Files & Assets, Brand & Design, Admin

## Local setup
1. Copy `.env.example` to `.env.local`.
2. Add the project's publishable key.
3. Run `npm install` then `npm run dev`.

Never commit secret/service-role keys.
